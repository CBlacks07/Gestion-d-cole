# Guide d'Utilisation

## Connexion

1. Accéder à l'application via votre navigateur
2. Entrer votre email et mot de passe
3. Cliquer sur "Se connecter"

## Tableau de bord

Le tableau de bord affiche:
- Nombre total d'élèves actifs
- Nombre de classes
- Recettes totales
- Répartition des élèves par cycle (Primaire, Collège, Lycée)

## Gestion des Élèves

### Ajouter un élève

1. Aller dans "Élèves"
2. Cliquer sur "Nouvel élève"
3. Remplir le formulaire:
   - Informations personnelles (nom, prénom, date de naissance, etc.)
   - Informations du tuteur (parent/gardien)
   - Classe assignée
   - Informations médicales (optionnel)
4. Cliquer sur "Enregistrer"

### Rechercher un élève

Utiliser la barre de recherche pour trouver un élève par:
- Nom
- Prénom
- Matricule

### Voir le détail d'un élève

1. Cliquer sur l'icône "œil" dans la liste des élèves
2. Consulter toutes les informations
3. Accès rapide aux notes, absences et paiements

## Gestion des Enseignants

### Ajouter un enseignant

1. Aller dans "Enseignants"
2. Cliquer sur "Nouvel enseignant"
3. Remplir les informations:
   - Informations personnelles
   - Diplômes
   - Matières enseignées
   - Type de contrat
4. Enregistrer

### Assigner des classes

Les enseignants peuvent être assignés comme enseignants principaux de classes depuis la section "Classes".

## Gestion des Classes

### Créer une classe

1. Aller dans "Classes"
2. Cliquer sur "Nouvelle classe"
3. Renseigner:
   - Nom de la classe
   - Niveau (CP1, CP2, CE1, CE2, CM1, CM2, 6ème, 5ème, 4ème, 3ème, 2nde, 1ère, Terminale)
   - Cycle (Primaire, Collège, Lycée)
   - Section (pour le lycée: A, C, D, etc.)
   - Enseignant principal
   - Effectif maximum
   - Frais de scolarité
4. Enregistrer

### Filtrer par cycle

Utiliser les boutons en haut pour filtrer les classes par:
- Tous
- Primaire
- Collège
- Lycée

## Gestion des Notes

### Saisir une note

1. Aller dans "Notes"
2. Cliquer sur "Nouvelle note"
3. Sélectionner:
   - Élève
   - Matière
   - Type d'évaluation (Devoir, Composition, Interrogation, TP, Examen)
   - Période (1er, 2ème ou 3ème Trimestre)
   - Note (sur 20)
   - Coefficient
4. Enregistrer

### Consulter un bulletin

1. Aller dans le détail d'un élève
2. Cliquer sur "Voir les notes"
3. Sélectionner la période
4. Le bulletin affiche:
   - Notes par matière
   - Moyennes
   - Moyenne générale
   - Rang dans la classe

## Gestion des Absences

### Enregistrer une absence

1. Aller dans "Absences"
2. Cliquer sur "Nouvelle absence"
3. Remplir:
   - Élève
   - Date
   - Période (Matin, Après-midi, Toute la journée)
   - Matière concernée (optionnel)
   - Justification (Oui/Non)
   - Motif si justifiée
4. Enregistrer

### Consulter les absences

- Filtrer par classe, date, statut
- Voir les statistiques globales
- Total des absences
- Absences justifiées vs non justifiées

## Gestion des Paiements

### Enregistrer un paiement

1. Aller dans "Paiements"
2. Cliquer sur "Nouveau paiement"
3. Sélectionner:
   - Élève
   - Type de paiement (Inscription, Scolarité, Cantine, Transport, Uniforme, Autres)
   - Montant
   - Mode de paiement (Espèces, Chèque, Virement, Mobile Money)
   - Mois concerné (pour les paiements mensuels)
4. Enregistrer

Le système génère automatiquement un reçu.

### Consulter l'historique des paiements

1. Aller dans le détail d'un élève
2. Cliquer sur "Historique des paiements"
3. Voir tous les paiements effectués
4. Total payé pour l'année

## Rapports et Statistiques

### Générer des rapports

1. Aller dans "Rapports"
2. Sélectionner le type de rapport:
   - Rapport financier
   - Rapport d'assiduité
   - Rapport de notes
   - Rapport d'effectifs
3. Choisir la période
4. Cliquer sur "Générer le rapport"
5. Télécharger en PDF ou Excel

### Rapport de classe

- Moyenne générale de la classe
- Classement des élèves
- Statistiques par matière
- Taux de réussite

### Rapport financier

- Recettes par type (Inscription, Scolarité, etc.)
- Recettes par mode de paiement
- Évolution mensuelle
- Taux de recouvrement

## Rôles et Permissions

### Administrateur
- Accès complet à toutes les fonctionnalités
- Gestion des utilisateurs
- Configuration du système

### Directeur
- Consultation de tous les rapports
- Gestion des élèves et enseignants
- Validation des opérations importantes

### Enseignant
- Saisie des notes pour ses matières
- Enregistrement des absences
- Consultation des élèves de ses classes

### Secrétaire
- Gestion des élèves
- Enregistrement des paiements
- Gestion des absences

## Conseils d'utilisation

1. **Sauvegardes régulières**: Demandez à votre administrateur système de configurer des sauvegardes automatiques

2. **Année scolaire**: Pensez à mettre à jour l'année scolaire en début d'année

3. **Archivage**: Les élèves diplômés ou transférés peuvent être marqués comme "inactifs" pour garder l'historique

4. **Rapports**: Générez des rapports régulièrement pour suivre les performances

5. **Mobile Money**: Pour les paiements Mobile Money, notez toujours le numéro de transaction

## Support

Pour toute assistance, contactez l'administrateur système ou créez un ticket sur le système de support.
